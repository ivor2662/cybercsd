新人導讀

TMS 是什麼？

TMS（Terminal Management System）是我們管理刷卡機（EDC）參數的後台。裝機、異動、拆機時，都要先在 TMS 設定該台機器的收單行（Acquirer）、NII、連線方式（撥接、網路、4G、TLS）、Linear 參數和各種功能開關。機器之後再從 TMS 下載參數。

常態性問題

掃碼特店設定（影響：每次 3~4 小時）

  • 台新提供的掃碼檔案不會提供 DTID（已向台新反應多年無果）
  • 須人工用 Excel 公式以 MID 比對案件清單檔 SID & Token Key 要裝給哪一台
  • 每當有大批新增掃碼或異動掃碼資訊，需花費 3~4 小時設定

TSB S80 → A80 換裝（影響：1 小時~半個工作天）

  • 台新出單寫「同舊機功能」，TMS 需人工檢查舊機客製化功能：
    • Logofile / 結帳後調閱編號歸1 / 是否自動結帳
    • 明細列印預授權 / 是否列印取消交易明細
    • 人工輸入可只印一聯 / VERSION / SETTIME / MASK 等
  • 並非所有客製化都能自動匯入，需人工設定
  • IATOMS 案件每次匯出限 100 筆，超過需分次匯出再整合

IM10 裝機/異動（影響：每次 1~2 小時）

  • IM10 無資產故無 IATOMS 建案，客服 mail 通知 TMS 設定
  • 需向客服確認要設定在哪個 TMS 環境
  • 客戶提供的工單問題多：MID 少 0 或有空格、票證資訊填反
  • 無法自動匯入，需人工調整
  • 異動時客戶不寫清楚要改什麼，TMS 要整個檢查，有時須整個重設

每日拆機件處理

  • 需逐筆檢查紀錄：工程師是否有上「無帳/清機/0結」等字樣
  • GP 因 DTID 會重複使用，需比對是否已刪除過再裝給新特店，以免誤刪
  • GP 有三個 TMS 環境需撈資料比對

新人易踩的坑（整理者歸納）

  • 測試機不一定走測試環境：銀行出的「測試機」可能是正式機，要先問清楚是開教育訓練模式，還是設定測試環境連線。指示改了也要留紀錄。
  • 工單內容要再確認：通訊方式（撥接或 TCP/IP）、有線或無線機型、Memo 寫的設定開關都可能互相矛盾或寫錯，有疑問先問客服再動手。
  • 匯入 IATOMS 後要再檢查一次：曾發生工單沒開電簽，匯入後卻自動開啟。匯入後要逐項確認，不要直接相信匯入結果。
  • TID 與 IATOMS 建案不同組時要留紀錄：不然多年後查到會誤以為設定錯了。
  • 掃碼 Token Key 常常沒給：台新的掃碼檔沒有 DTID，要用 MID 比對 SID 和 Token Key 才知道裝給哪一台。
  • S80 → A80「同舊機功能」不會自動帶過去：要人工逐項比對舊機的客製化（Logofile、自動結帳、MASK 等）。
  • IATOMS 一次只能匯出 100 筆：超過要分批匯出再合併。
  • IM10 沒有 IATOMS 案件：要先跟客服確認設定在哪個 TMS 環境，也要檢查 MID 少 0、有空格，或票證資訊填反。
